ChalaDev v1.0.0

Suite de utilidades locales en el Side Panel (Manifest V3) para desarrolladores web y diseñadores UI/UX: cuentagotas WCAG, inspector DOM, JSON/Base64URL/JWT offline, QR y SEO, además de Red (Performance + fetch/XHR), Aplicación (Manifest, Storage, WebMCP) y Security Overview.

  • Compatibilidad: Google Chrome >= 116, Microsoft Edge >= 116 y Node.js >= 22 (detección progresiva de EyeDropper y WebMCP navigator.modelContext)
  • Código fuente de la extensión: src/
  • Compilación lista para cargar descomprimida: dist/build/ChalaDev.chromium/
  • Pruebas automatizadas: node tests/verify.mjs
  • Repositorio oficial: github.com/joelchala/ChalaDev
