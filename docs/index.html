ChalaDev

Suite de utilidades locales en el Side Panel para desarrolladores web y diseñadores UI/UX en Chrome y Microsoft Edge: cuentagotas con contraste WCAG, inspector DOM, JSON/Base64URL/JWT offline, generador QR local y auditoría SEO rápida.

  • Código fuente de la extensión: src/
  • Compilación lista para cargar descomprimida: dist/build/ChalaDev.chromium/
  • Pruebas automatizadas: node tests/verify.mjs
  • Repositorio oficial: github.com/joelchala/ChalaDev
